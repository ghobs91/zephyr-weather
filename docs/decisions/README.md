# Architecture Decision Records

This directory records significant architectural decisions for Zephyr Weather.

## Convention

- **Filename**: `NNNN-short-title.md` (e.g. `0001-track-ios-pods-in-git.md`), zero-padded sequential numbers.
- **Status**: one of `proposed`, `accepted`, `superseded`, `deprecated`.
- **Required sections**: Context, Decision, Consequences, Alternatives Considered.
- Use [`0000-template.md`](0000-template.md) for new records.

No ADRs exist yet — records should be added as decisions are made, not retroactively invented.
